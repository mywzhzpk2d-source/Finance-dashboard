# BJ Market Terminal

index.html에는 스타일과 스크립트가 포함되어 있습니다. 기존 GitHub Pages의 index.html을 교체하면 적용됩니다. style.css와 script.js는 동일한 코드의 별도 복사본입니다.

## 수정 내용
- 미국 2년물(TVC:US02Y), 10년물(TVC:US10Y) 금리를 별도 일봉 캔들 차트로 표시
- 장단기 스프레드, M2, 구리, 다우존스, 코스피 차트 제거
- VIX(TVC:VIX)를 검은 배경의 일봉 캔들 차트로 표시
- 매매일지와 관심종목 메뉴, 화면, 관련 스크립트 제거
- AI Analyst, 뉴스룸 및 나머지 매크로 구성 유지

## 실행
인터넷이 연결된 브라우저에서 index.html을 열거나 GitHub Pages에 업로드하세요. 외부 TradingView 위젯의 데이터와 표시 가능 여부는 공급자 환경에 따라 달라질 수 있습니다.
